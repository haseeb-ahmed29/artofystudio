# Self-hosted fonts

These unmodified Latin WOFF2 variable fonts are served locally, with `font-display: swap` in the website stylesheet. They require no font service at runtime.

| Family | File | Weight range | Source |
| --- | --- | --- | --- |
| Outfit | `outfit-latin-variable.woff2` | 100–900 | [Google Fonts](https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2) |
| Inter | `inter-latin-variable.woff2` | 100–900 | [Google Fonts](https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2) |
| Caveat | `caveat-latin-variable.woff2` | 400–700 | [Google Fonts](https://fonts.gstatic.com/s/caveat/v23/Wnz6HAc5bAfYB2Q7ZjYY.woff2) |
